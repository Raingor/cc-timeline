6月7号的log:
- 早上吃了个早茶，这个澡擦好就非常有趣了,我们在宁徽园里喝早茶，我们本以为要拿号排队的，因为这家店好多人。然后可能是服务员都不清楚流程的原因，导致了我们没有排队就被带进去了，然后带进去之后也差不多相当于免排队吧，虽然有些小插曲，可是还是比较快的让我们有位置坐下来了。都比较正常的点了4个点心。可是这家的早茶店就非常的让人感觉到无语，我们吃完一笼就有服务员把笼子收走了，吃到最后，整个桌子只剩下一笼，我们故意不吃完放着，看着好像吃完之后就好像没有吃过的痕迹，桌子上非常干净，就只剩两个茶杯和一笼点心。感觉挺不礼貌的一种服务行为，催单也是，催单的时候服务员竟然说，比较多人都要等的了，催也没用，竟然有这样的说辞，我以为是”在加急的了，等下哈“，这样去安抚一下我们，这让我和CC一下就无语住了，我们俩相视而笑，看着吃完后，就只剩下两个杯子没被收走了，我们以后也不会再去宁徽园喝茶了，本是带着好奇心去的。
- 下午，我和CC去买了一家，她推荐的一款蛋糕，然后带着蛋糕去了一家，非常化学感觉的一家咖啡店，虹吸咖啡，非常的～有实验室的感觉，我们也是品上了高端的咖啡。当然，对CC来说是能品的出咖啡的不同做法，实质对我来说，我感觉咖啡的味道好像差不多～。我听CC描述咖啡的学问，就像我跟CC描述AI一样，谜语一般的，完全听不懂，也品不会。不过，那家店还是很舒服的，比较宁静宜人，很chill。
- 傍晚，我和CC回去CC家，带着她爸妈一起去了石岐，因为她爸妈也很少出去走走，然后CC也想带着他们出去走走，一起吃个饭，吃我们平时喜欢吃的，让他们也感受下，中山市区的变化。一路上都是大雨滂沱，然后到了目的地后，就没下雨了，也是一种幸运！我们也如愿的一起在大墩荣记里吃上了，这家店我和CC之前吃过了两次了，感觉好好吃！所以这次把CC的爸妈带上来分享～。饭后，和他们一起逛了步行街，让他们也重回旧时路。一路上CC爸妈也是感慨，整个步行街变化很大，他们以前也是来过，所以会和自己的以前的记录进行对比，感叹着。走了一圈后，我们也回程了。
- 回程后，我和CC再去散了一下步，聊了下只属于我们两个人的时光。“十年后，你希望我怎么评价你”，对我来说，十年后，我希望的是你对我的评价依旧是，“十年不变，保持初心，依然可靠，一心守护”，过去不论怎么样，现在最爱你的人，最疼你的人，就只能是我了，无论是什么样的未来，我会和你一起去面对，一起去享受！
- 当我准备开车回广州的时候，CC留了一封信，让我回家再看，我就带着这种开心和对未知的兴奋，提神醒脑，一路回广州的高速上都是很顺畅。回家后，洗完澡在最舒服的环境下，一字一句的看了CC给我写的信，信封也是CC的手绘，太用心了，工作的我，还有接CC的专用车，都是她手工画上去的，蜡笔的痕迹还能摸到，太有感觉了。内容是我们俩一起的回忆，也是她对我的一次评价，我也很感谢能遇到CC，让我能再有爱一个人的能力，我会好好的的爱你，会疼着你。我的行为或言语细节，都被你记到心里。真的很好，这封信内容，比高考作文还看得舒服and开心。行动派来的，所以说会吻着你，一直陪着你，这不是短暂的行动，而是一直，一直的行动～，我会好好地爱你，好好地爱护你，有什么事我都会依旧站起你身边，最吻你的人，best，top，just me！
